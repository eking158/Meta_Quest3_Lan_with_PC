# Quest 3 유선 랜 연결 도우미

라우터 없이 랜선 하나로 우분투 PC와 Meta Quest 3를 연결해 주는 도구입니다.
아래처럼 바탕화면 아이콘을 한 번 설치하면, 이후 사용 방법은 아이콘을 실행했을 때 화면에서 단계별로 안내합니다.

## 아이콘 설치 (처음 한 번만)

1. 이 폴더에서 터미널을 엽니다. (폴더 빈 곳을 우클릭 → **터미널에서 열기**)
2. 아래 명령을 붙여넣고 엔터를 누릅니다. `sudo`는 붙이지 마세요.

   ```bash
   bash install-desktop-shortcut.sh
   ```

3. 바탕화면에 아이콘 2개가 생깁니다.
   - **Quest 3 LAN 원터치 연결**: 연결 설정, 상태 확인, 해제, 준비물 안내 메뉴
   - **Quest 3 LAN 연결 해제**: 설정을 바로 원래대로 되돌림
4. 처음 더블클릭할 때 "신뢰할 수 없는 실행 파일" 경고가 나오면, 아이콘을 우클릭한 뒤 **실행 허용**을 누릅니다.

이후로는 **Quest 3 LAN 원터치 연결** 아이콘을 더블클릭하고, 화면에 나오는 안내를 따라가면 됩니다.

> 스크립트(`quest3-lan-setup.sh`)를 새 버전으로 바꿨다면 2번 명령을 한 번 더 실행해야 아이콘에 반영됩니다.

## 제거 방법

꼭 **1 → 2 순서**로 진행하세요. 아이콘을 먼저 지우면 연결 설정을 해제할 아이콘도 없어집니다.

1. **연결 설정 해제**: 바탕화면의 **Quest 3 LAN 연결 해제** 아이콘을 더블클릭하고, 암호를 입력한 뒤 `y`를 누릅니다.
   - 이 PC의 랜 포트가 원래 상태로 돌아갑니다. 직접 만든 유선 설정은 그대로 남습니다.
   - 아이콘이 없다면, 이 폴더에서 터미널을 열고 아래 명령을 실행해도 됩니다.

     ```bash
     sudo bash quest3-lan-setup.sh --uninstall
     ```

2. **아이콘 제거**: 이 폴더에서 터미널을 열고 아래 명령을 실행합니다. `sudo`는 붙이지 마세요.

   ```bash
   bash install-desktop-shortcut.sh --uninstall
   ```

3. (선택) 이 폴더를 지웁니다. 이제 PC에 남은 것은 설치 때 받은 `dnsmasq-base` 프로그램뿐입니다. 이 프로그램은 다른 프로그램(NetworkManager 등)이 함께 쓰는 경우가 많으니 그대로 두는 것을 권장합니다.
